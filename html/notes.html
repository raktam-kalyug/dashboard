CSS Grid — Key Concepts

The CSS Grid Layout Module offers a grid-based layout system, with rows and columns, making it easier to design web pages without having to use floats and positioning.

Core Properties

  • display: grid — activates grid on the container
  • grid-template-columns — defines column tracks
  • grid-template-rows — defines row tracks
  • grid-template-areas — named layout areas
  • gap — spacing between tracks

Useful Functions

  • repeat(3, 1fr) — repeat 3 equal columns
  • minmax(200px, 1fr) — min 200px, max flexible
  • auto-fill vs auto-fit — auto-fill keeps empty tracks, auto-fit collapses them
Key exam tip: grid-area is shorthand for grid-row-start, grid-column-start, grid-row-end, grid-column-end.
